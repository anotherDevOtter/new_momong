# 디자인 제안 핵심 방향 — 도출 로직 (규칙 기반)

> 3WAY 컨설팅 "컨설팅 요약" 화면([ConsultingSummary.tsx](../frontend/user/src/components/3way/ConsultingSummary.tsx))의
> **"디자인 제안 핵심 방향"** 섹션을 어떤 입력으로 어떻게 도출하는지에 대한 설계 스펙.
> 상태: **설계 승인 대기 → 구현 예정** (기존 코드는 선택 유무로만 분기하는 고정 문구였음, TODO Q3)

---

## 배경 / 제약

- 이 화면은 **얼굴 분석 이전 단계**(Step 4)라 얼굴 분석값(W/N/C·S/N/H)을 **쓸 수 없음**.
- 가용 입력:
  - 이미지 선호 키워드 (선호 / 비선호) — 10개
  - 패션 스타일 (선호 / 비선호) — 7개
  - 고객 기본정보, 선택 코스
- 기존 구현은 "선호 항목이 하나라도 있으면 항상 동일한 고정 문구" 반환 → 실제 선택을 반영 못 함.

## 설계 원칙

선택값을 앱이 이미 쓰는 **이미지 타입 2축**(Tone: Warm↔Cool / Balance: Soft↔Hard)에 투표시켜
대표 방향 1칸을 도출하고, **표준 사전 `hairImageMap`**([ImageDirectionSetting.tsx](../frontend/user/src/components/3way/ImageDirectionSetting.tsx) 내 정의)의
해당 칸 `keywords`·`details`를 그대로 사용한다.
→ 새 카피를 지어내지 않고, 이미지 방향 단계와 **일관된 어휘**를 유지.

## 메커니즘

```
1) 두 축에 가중치
   - Tone축:    Warm = -1, Neutral = 0, Cool = +1
   - Balance축: Soft = -1, Neutral = 0, Hard = +1

2) 투표
   - 선호 선택: 해당 키워드/스타일의 (tone, balance) lean 을 그대로 +
   - 비선호 선택: 반대로 밀어냄 (lean 부호 반전해서 +)

3) 합산 → 부호로 결정
   - toneSum  < 0 → W,  = 0 → N,  > 0 → C
   - balSum   < 0 → S,  = 0 → N,  > 0 → H
   - 선택이 전혀 없으면 → N/N (내추럴)

4) 조회
   - key = `${tone}/${balance}`  (예: 'C/S')
   - hairImageMap[key] 의 keywords / details 사용

5) 출력
   - 요약 문구: "고객은 {keywords 상위 2개} {ToneLabel}·{BalanceLabel} 이미지를 선호합니다."
                + 비선호가 있으면 "~ 무드는 지양합니다." 덧붙임
   - 제안 전략: hairImageMap[key].details  (+ designs 있으면 함께)
```

## 매핑표

### 이미지 키워드 (10) → (Tone / Balance)
대부분 hairImageMap 의 keywords 와 직접 일치하도록 매핑.

| 키워드 | 매핑 | 근거 (사전 키워드) |
|--------|:---:|------|
| 귀여운 / 사랑스러운 | W/S | 귀여운·사랑스러운 |
| 어려보이는 | N/S | 젊은 |
| 프레시한 | N/S | 산뜻한 |
| 청초한 | C/S | 청초한 |
| 부드러운 / 여성스러운 | W/H | 부드러운·여성스러운 |
| 단아한 | N/N | 단아한 |
| 시크 / 세련된 | C/N | 세련된 |
| 우아한 / 클래식한 | N/H | 우아한 |
| 자연스러운 | N/N | 자연스러운 |
| 지적인 / 현대적인 | C/N | 지적인 |

### 패션 스타일 (7) → (Tone / Balance)

| 스타일 | 매핑 |
|--------|:---:|
| 클래식 | N/H |
| 페미닌 | W/H |
| 캐주얼 | N/S |
| 드뮤어 | N/N |
| 미니멀 | C/N |
| 힙시크 | C/H |
| 스트릿 | C/H |

### hairImageMap 9칸 참고 (keywords / details)

| key | keywords | details |
|-----|----------|---------|
| W/S | 귀여운·순진한·사랑스러운 | 짧아짐·웨이브·앞머리·가벼운 질감 |
| N/S | 생기있는·젊은·산뜻한 | 짧음·자연스러운 질감 |
| C/S | 청초한·깨끗한·신선한 | 짧음·직선·깔끔한 컷 |
| W/N | 쾌활한·발랄한·명랑한·활동적인 | 곡선·부드러움 |
| N/N | 내추럴 | 자연스러운·수수한·담백한·단아한 |
| C/N | 세련된·심플한·스마트한·샤프한·지적인 | 직선·선명함 |
| W/H | 부드러운·여성스러운·화려한·섹시한 | 길어짐·웨이브·부드러운 곡선·무게감 |
| N/H | 우아한·고상한·차분한 | 길어짐·무게감 |
| C/H | 도회적인·기품있는·현대적인 | 길어짐·스트레이트·직선·무게감 |

## 예시

선호 = [청초한, 미니멀], 비선호 = 없음
- 청초한 → C/S (tone +1, bal −1), 미니멀 → C/N (tone +1, bal 0)
- toneSum = +2 → **C**, balSum = −1 → **S** → key **C/S**
- 요약: "고객은 청초·깨끗한 Cool·Soft 이미지를 선호합니다."
- 제안 전략: 짧음 · 직선 · 깔끔한 컷

## 애매/조정 후보

도메인 검토 필요 항목 (현재 초안 값):
- **프레시한** → N/S (대안: C/S 신선한)
- **우아한/클래식한** → N/H (대안: C/H)
- **클래식**(패션) → N/H (대안: C/H)
- **페미닌**(패션) → W/H (대안: W/S — 로맨틱·스위트로 보면)

## 향후 확장

- 얼굴 분석 *이후* 단계(이미지 방향/리포트)에서는 이 선호 기반 "희망 방향"과
  실제 얼굴 분석 "현재 타입"을 **대비**해 전략(강조/활용/중화)을 제시할 수 있음.
