메르시모몽 · Algorithm v4

3WAY 분석 알고리즘

Layer 1 타입 확정(불변) → Layer 2 이미지 벡터 산출 → Layer 3 Modifier 벡터 보정 → Layer 4 Sensual 독립 점수
각 레이어는 역할이 완전히 분리된다. 하위 레이어는 타입을 절대 변경하지 않는다.
핵심 개념 분리 — Identity vs Expression
타입(Identity)과 이미지 벡터(Expression)는 완전히 다른 개념이다. 이름이 유사해도 절대 혼용하지 않는다. 예) 타입 "CUTE(귀여운)"과 벡터 "귀여움"은 별개다. 타입은 Layer 1에서 확정되며 이후 어떤 레이어도 변경할 수 없다.
구분 개념 결정 레이어 값의 종류 변경 가능 여부
Identity 이미지 타입 — 얼굴의 전체 이미지 방향. 9개 중 1개. Layer 1 전용 CUTE / CHIC / PURE 등 9개 중 1개 (고정값) 불변. 절대 변경 불가.
Expression 이미지 벡터 — 얼굴 인상의 구성 속성. 8개 각각 수치. Layer 2·3에서 산출 귀여움 72 / 세련됨 58 / ... (연속 수치) Layer 2·3에서 산출·보정 가능.
알고리즘 파이프라인 — 4 Layer 직렬 구조
L1
Layer 1 · Identity
이미지 타입 확정
축1(Warm/Neutral/Cool) × 축2(Soft/Natural/Hard) 교차 → 9개 타입 중 1개 확정.
OUT → Identity: CUTE / FRESH / PURE / SOFT / NATURAL / CHIC / FEMININE / ELEGANT / MODERN
⚠ 이후 어떤 레이어도 Identity를 변경하지 않는다.
L2
Layer 2 · Expression
이미지 벡터 산출
핵심변수 7개를 매핑 테이블에 대입 → 8개 벡터 점수 산출. 타입 점수를 다시 계산하지 않는다.
IN → 핵심변수 7개 측정값 (눈꼬리 각도, 눈썹~눈 거리, 눈 가로:세로, 눈 사이 간격, 입술 세로비율, 얼굴 가로:세로, 코 높이)
OUT → Vec[귀여움, 청순함, 발랄함, 단아함, 우아함, 세련됨, 도회적, 지적임] = 각 수치
⚠ 타입 점수 계산 없음. 벡터만 출력.
L3
Layer 3 · Modifier
쌍꺼풀 형태 벡터 보정
쌍꺼풀 형태(무쌍/속쌍/세미아웃/아웃라인) → 이미지 벡터 수치를 미세 조정. 타입 변경 없음.
IN → Layer 2의 Vec + 쌍꺼풀 형태 체크값
OUT → Vec_adj = Vec + Modifier_delta (타입은 그대로)
⚠ 벡터만 조정. 타입(Identity)에 관여 없음.
L4
Layer 4 · Sensual
Sensual 독립 점수
타입에도 관여하지 않고, 이미지 벡터에도 관여하지 않는다. 별도의 속성으로 항상 독립 산출.
IN → 눈꼬리 올라감 정도 / 입술 볼륨·입꼬리 / 삼백안 정도 (3개 전용 변수)
OUT → Sensual % (0~100. 타입·벡터와 무관한 독립값)
⚠ 타입 변경 없음. 벡터 조정 없음. 독립 출력.
Layer 1 — 이미지 타입 확정 (Identity)

타입(Identity)은 이 단계에서 확정된다. 이 셀의 이름(CUTE·CHIC 등)은 고유 타입명이며, Layer 2의 이미지 벡터(귀여움·세련됨 등)와 이름이 유사해도 별개 개념이다.
Layer 2 — 이미지 벡터 산출 (Expression)
Layer 2는 타입 점수를 다시 계산하지 않는다. 핵심변수 7개는 사람 얼굴이 주는 인상(impression)의 강도를 8개 벡터 수치로 변환한다. 벡터 점수가 타입 방향과 달라도 Identity는 변경하지 않는다.
핵심변수 7개 → 이미지 벡터 8개 매핑 테이블
측정 방향 기준: 각 변수의 "높은/올라간/넓은/긴/도톰한" 방향일 때의 벡터 기여값. 반대 방향이면 부호가 반전된다.
수치 범위: +2 강기여  +1 약기여  0 무기여  −1 약역방향  −2 강역방향
핵심변수 축 귀여움 청순함 발랄함 단아함 우아함 세련됨 도회적 지적임
눈꼬리 각도
(올라갈수록 →)		 W축 −2 0 −1 0 0 +2 +1 0
눈썹~눈 거리
(좁을수록 →)		 S축 −2 −1 −1 0 0 +2 +1 +2
눈 가로:세로 비율
(가로길수록 →)		 W축 −2 +1 −1 0 0 +1 0 +2
눈 사이 간격
(넓을수록 →)		 S축 +2 +2 +1 0 0 −1 −1 −2
입술 세로 비율
(도톰할수록 →)		 W축 +1 −1 0 +2 0 0 0 0
얼굴 가로:세로
(길수록 →)		 S축 −2 0 −1 0 +2 +1 +2 +1
코 높이
(높을수록 →)		 W축 −1 0 0 0 +1 +1 +2 0
읽는 법: 눈꼬리가 올라간 사람 → 귀여움 −2, 청순함 −1, 세련됨 +2, 도회적 +1 적용.
눈꼬리가 내려간 사람 → 부호 반전 → 귀여움 +2, 청순함 +1, 세련됨 −2, 도회적 −1 적용.
수치는 현재 가-설계 기준이며, 실제 케이스 데이터 축적 후 검증·보정 예정.
벡터 계산 예시
눈꼬리 내려감: 귀여움 +2, 청순함 +1, 세련됨 −2, 도회적 −1
눈 사이 넓음: 귀여움 +2, 청순함 +2, 발랄함 +1, 세련됨 −1, 도회적 −1
입술 도톰: 귀여움 +1, 청순함 −1, 단아함 +2
────────────────────────────
귀여움 합산: +2 +2 +1 = +5 / 세련됨 합산: −2 −1 +0 = −3 / 단아함: +2
Layer 3 — Modifier · 쌍꺼풀 형태 벡터 보정
Modifier는 이미지 벡터만 미세 조정한다. 쌍꺼풀 형태는 Layer 1 타입 판정 변수에 포함되지 않으므로 독립 보정자로 분리. 타입(Identity) 변경 없음.
Modifier → 이미지 벡터 수치 테이블
쌍꺼풀 형태 귀여움 청순함 발랄함 단아함 우아함 세련됨 도회적 지적임 근거
무쌍 −2 0 0 0 0 +2 +1 0 눈매 라인 드러나 날카롭고 선명
속쌍 (인라인) 0 0 0 0 0 0 0 0 자연스러운 기준형. 보정 없음.
세미아웃 −1 0 0 0 0 +1 0 +1 입체감·존재감 추가, 다소 또렷
아웃라인 +1 0 0 +2 0 −1 0 0 넓은 쌍꺼풀, 눈 볼륨·화려함↑
Modifier 수치는 Layer 2 벡터 합산값에 가산된다. 예) Layer 2 세련됨 = +3, 무쌍 Modifier = +2 → 최종 세련됨 = +5.
Layer 4 — Sensual · 완전 독립 점수
Sensual은 타입에 관여하지 않고 이미지 벡터에도 관여하지 않는다. 8개 이미지 벡터 중 어떤 것도 조정하지 않는다. 얼굴이 가지는 관능적 인상 강도를 별도 속성으로 독립 산출한다.
Layer 2와 변수 공유 여부: 눈꼬리 각도와 입술 세로 비율은 Layer 2(이미지 벡터)에서도 사용된다. 이것이 중복 계산이 아닌 이유는 역할이 다르기 때문이다.
· Layer 2에서 눈꼬리 각도 → 세련됨/도회적/귀여움 벡터에 기여 (인상의 구성 요소)
· Layer 4에서 눈꼬리 각도 → Sensual 강도 점수에 기여 (관능적 속성의 강도)
같은 얼굴 특징이지만 측정 목적이 다르다. 두 레이어는 출력값이 다르며 서로 영향을 주지 않는다.

v4 수정 사항
수정
Layer 2에서 타입 점수 재계산 구조 완전 제거. 기존 "확률 분포로 Primary/Secondary 타입 결정" 로직 삭제. Layer 2는 벡터만 출력.
수정
Identity(타입명)와 Expression(벡터명) 개념 분리 명시. "CUTE(타입)"와 "귀여움(벡터)"을 명확히 구분하는 개념 분리 테이블 추가.
수정
핵심변수 × 벡터 매핑 테이블 수치화. 기호(●●/▼) 대신 −2/−1/0/+1/+2 수치로 대체. 측정 방향 기준 명시.
수정
Modifier 벡터 수치 테이블 작성. 4가지 형태 × 8개 벡터의 가감 수치 정의. 속쌍(인라인)은 기준형(±0) 명시.
수정
Layer 순서 재정의. 1(Identity) → 2(Expression) → 3(Modifier) → 4(Sensual). 이전 Modifier가 Layer 3과 Sensual 사이에 삽입된 구조 정리.
수정
Sensual 변수 공유 관련 역할 분리 설명 명시. 눈꼬리·입술 변수가 Layer 2와 Sensual에 모두 사용되는 이유를 "측정 목적 다름"으로 설명. 중복 계산이 아님을 구조적으로 명시.
유지
축1(W·N·C) 8항목 / 축2(S·N·H) 8항목 / 9개 타입 / 3×3 맵 구조 변경 없음.
유지
Sensual 가중치 합산 % 방식 유지. 눈꼬리 2.0 / 입술볼륨 1.5 / 삼백안 1.0 → 합계 4.5pt = 100%.
