## Step 5 — 디자인 제안 핵심 방향

### 이미지 키워드

| 선택지 | 아웃풋 |
|------|------|
| 귀여운 / 사랑스러운 | 짧아짐 · 웨이브 · 앞머리 · 가벼운 질감 |
| 어려보이는 | 짧음 · 자연스러운 질감 |
| 프레시한 | 짧음 · 자연스러운 질감 |
| 청초한 | 짧음 · 직선 · 깔끔한 컷 |

| 단아한 | 자연스러운 · 담백한 질감 |
| 시크 / 세련된 | 직선 · 선명함 |
| 우아한 / 클래식한 | 길어짐 · 무게감 |
| 자연스러운 | 자연스러운 · 담백한 질감 |
| 지적인 / 현대적인 | 직선 · 선명함 |

| 선택지 | 아웃풋 |
|------|------|
| 클래식 | 길어짐 · 무게감 |
| 페미닌 | 길어짐 · 웨이브 · 부드러운 곡선 · 무게감 |

### 예시

**예시 1.** `청초한` + `미니멀` 선택
→ **짧음 · 직선 · 깔끔한 컷**

**예시 2.** `부드러운/여성스러운` + `페미닌` 선택
→ **길어짐 · 웨이브 · 부드러운 곡선 · 무게감**

## Step 8 — 이미지 밸런스 분석 요약

### 톤 (Warm / Neutral / Cool)

| 선택지 | 아웃풋 |
|------|------|
| Warm | 따뜻하고 부드러운 톤 |
| Neutral | 치우침 없는 중립 톤 |
| Cool | 맑고 시원한 톤 |

### 무드 (Soft / Neutral / Hard)

| 선택지 | 아웃풋 |
|------|------|
| Soft | 둥글고 부드러운 인상 |
| Neutral | 균형 잡힌 인상 |
| Hard | 또렷하고 선명한 인상 |

### 얼굴비율 (세로:가로)

| 선택지 | 아웃풋 |
|------|------|
| 짧음 (≤1.3) | 동안형의 짧은 얼굴 비율 |
| 평균 (1.4~1.5) | 안정적인 표준 얼굴 비율 |
| 김 (≥1.51) | 성숙하고 긴 얼굴 비율 |

### 중안부 (비율)

| 선택지 | 아웃풋 |
|------|------|
| 짧음 (~1.5:1) | 중안부가 짧아 또렷한 인상 |
| 평균 (~2:1) | 균형 잡힌 중안부 |
| 김 (2.5:1~) | 중안부가 길어 시원한 인상 |

### 예시

**예시 1.** Cool · Hard · 얼굴비율 김 · 중안부 평균
→ 맑고 시원한 톤
→ 또렷하고 선명한 인상
→ 성숙하고 긴 얼굴 비율
→ 균형 잡힌 중안부

**예시 2.** Warm · Soft · 얼굴비율 짧음 · 중안부 짧음
→ 따뜻하고 부드러운 톤
→ 둥글고 부드러운 인상
→ 동안형의 짧은 얼굴 비율
→ 중안부가 짧아 또렷한 인상
